# Sistema-Distribuido-de-Mensajer-a-con-Comunicaci-n-TCP-RPC-y-SOAP
Tecnologías: C - Python - TCP/IP - Sockets - Pthreads - RPC - SOAP - Spyne - Zeep: Desarrollo de un sistema cliente-servidor TCP concurrente en C mediante Pthreads. Gestión concurrente de usuarios, colas FIFO, mensajería y envío de archivos. Integración de RPC y SOAP para registro de operaciones y normalización de mensajes.
